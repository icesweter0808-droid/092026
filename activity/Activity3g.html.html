Introduction of Paragrapgh Tag

In HTML, paragraph are defined with the p tag.
A paragraph element in an HTML document is made up of content,br> such as text, images, or other content
which appears between an opening p tag and closing p tag.

p tag is the HTML tag for a paragraph. Adding the p tag to an HTML doc, followed bt text, will create a paragraph on your page.
Adding the closing p tag will end the paragraph.
